# GerberCraft · 浏览器本地 Gerber 看图与工艺检查工具

面向工控小板打样前的图纸自检场景。**所有 Gerber/钻孔解析、渲染、工艺检查都在浏览器本地完成，原始文件不发起任何网络请求、不写入磁盘。**

## 解决的问题

- 老师傅肉眼对 Gerber 查线距，漏一处废一批板
- 板厂推荐的检查软件按工位收费、装一堆依赖
- 图纸外发有泄密风险

## 技术栈

Vite + React 18 + TypeScript（严格模式），Zustand 状态管理，fflate 解 zip，Canvas 2D 渲染，IndexedDB 存工单元数据，Vitest 单测。无后端、无外部服务。

## 启动

```bash
npm install
npm run dev      # 开发
npm run test     # 单元测试（解析器/几何/层识别/钻孔）
npm run build    # 生产构建，产物纯静态可离线部署
```

## 解析器准确性设计（最关键）

`src/core/gerber/` 与 `src/core/excellon/` 是纯 TS 实现的 RS-274X / Excellon 解析器，单测覆盖易错点：

- **宏光圈 AM**：独立表达式求值器（`macroExpr.ts`），支持 `$n` 变量、`+ - x /`、括号、一元负号；实例化支持 1/2/20/21/22 图元与 clear 子图元
- **圆弧**：G74 单象限（方向由几何决定）与 G75 多象限（G02/G03 扫向）两套规则，弦高 5µm 细分，整圆识别
- **区域填充**：多轮廓走 Canvas `evenodd` 奇偶规则，岛/洞正确
- **负片极性**：`LPC` 后的 clear 图元用 `destination-out` 在层离屏内擦除，层间再按透明度叠加，极性不会反
- **坐标**：FS 格式、前导/尾随零抑制、显式小数、英寸/mm 统一换算到 mm
- **步进重复 SR、块光圈 AB**：复制平移与块模板闪光
- **Excellon**：刀表 C 直径、PTH/NPTH、G85/M15/M16 路由槽、零抑制自动识别

## 性能（几十万图元）

- 离屏分层瓦片缓存（`tileCache.ts`）：20mm 板坐标分块，按缩放档缓存，平移只贴瓦片、跨档才重画，LRU 400 块/层
- 视口裁剪：相机只请求可见范围瓦片
- 栅格分析（网络/线距/对比）最长边限 4096px 自适应降分辨率，Union-Find 连通域 + Felzenszwalb 两趟距离变换，避免 O(n²)

## 已知边界（车间使用前注意）

- 宏图元 4（热焊盘）按带孔圆近似，5/6/7（莫尔条纹等老图元）未实现会告警，遇到需人工复核
- 网络提取基于铜皮连通域，无设计网表时"短路"是启发式判定（同域多焊盘且无灌铜）
- DRC 线距走栅格（默认 10µm），精度受分辨率限制；矢量线宽检查是精确的
- 块光圈 AB 已支持基础模板，嵌套块未覆盖
